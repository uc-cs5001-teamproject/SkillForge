## Project Topic:
Project SkillForge is aimed at improving the usability and capability of autonomous robot learning from exo-centric (3rd-person) human demonstrations.  The goal of the project is to create a system of easily going from human demonstrations in videos to a robot policy model capable of performing the demonstrated task in a simulation environment.  While academic research has created disparate parts of the planned pipeline, components such as real->sim training and learning from demonstrations have yet to be combined into a user-focused product.
